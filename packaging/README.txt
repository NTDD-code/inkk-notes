                          INKK - HANDWRITTEN NOTES
                         Version 0.1.0 - Windows x64
========================================================================

Thank you for downloading Inkk!

1. QUICK START
------------------------------------------------------------------------
- Double-click `inkk.exe` to run immediately (standalone portable).
- Press F11 anytime to enter/exit borderless Fullscreen mode.
- Press F1 to view and customize all Keyboard Shortcuts.
- Right-click anywhere on the whiteboard canvas for quick actions.

2. FEATURES
------------------------------------------------------------------------
- Natural, pressure-responsive handwriting with C++ One-Euro stabilizer.
- Full-screen straight ruler (R) and 360-degree circular protractor (Shift+R).
- Built-in MATLAB mathematical engine (M) & Flowchart studio (Ctrl+F).
- Automatic background autosave and session crash recovery.
- Vector PDF export (Ctrl+Shift+E).
- Automatic update detection so you always stay up to date.

3. AUTO-UPDATES
------------------------------------------------------------------------
Inkk automatically checks for updates in the background. You can also
manually check for updates anytime by right-clicking the canvas and 
selecting "Check for Updates...".
